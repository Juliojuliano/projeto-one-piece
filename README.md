# Projeto One Piece

Página estática que apresenta os personagens principais dos Piratas do Chapéu de Palha (One Piece). Ao clicar em um dos botões com a foto da tripulação, o personagem correspondente é exibido em destaque com sua descrição.

## Tecnologias

- HTML5
- CSS3 (media queries para responsividade)
- JavaScript puro (DOM)

## Como visualizar

Não há dependências para instalar nem servidor para rodar. Basta abrir o arquivo `index.html` (na raiz do projeto) diretamente no navegador.

## Estrutura

- `index.html` — página principal
- `js/index.js` — lógica de seleção de personagem
- `src/css/` — estilos (`reset.css`, `estilos.css`, `responsivo.css`)
- `src/imagens/` — imagens dos personagens e da tripulação
